# Desertfishmenu

Menú bilingüe de Desert Fish, construido con Astro. Incluye el menú de cocina,
mariscos frescos, horario y enlaces a redes sociales.

## Desarrollo local

```bash
npm install
npm run dev
```

La aplicación se abre en `http://localhost:4321/`.

## Verificación y producción

```bash
npm run check
npm run build
```

## Contenido

- Selector Español / English; en inglés, los precios muestran el sufijo `MXN`.
- Menú principal de Desert Fish.
- Sección de mariscos frescos, sin precios.
- Horario de atención y enlaces a Facebook, Instagram y WhatsApp.
